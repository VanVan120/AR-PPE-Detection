# Grouped-split retrain: the measured results behind the corrected detector numbers
Evaluations of both checkpoints on the source-grouped PPE split, their training curves and recipes, and the run and split records; start with `READ_FIRST.md`.
The `time` column in `stage1/results.csv` and `stage2/results.csv` restarts at each resumed training session, so it is not the run's total time.
The weights (`best_grouped.pt`, `best_grouped_stage1.pt`, `best_refined.pt`) are in the GitHub release, not in this repository.
