# Python 3.11+

# IMPORTANT — onnxruntime vs onnxruntime-gpu: install ONLY ONE. Both provide the
# module `onnxruntime`. ultralytics will try to auto-install `onnxruntime-gpu`
# whenever torch sees a CUDA device (its exporter.py does this), and if the host's
# CUDA/cuDNN don't match that build you get a runtime that ADVERTISES a CUDA
# provider it cannot load — which makes ONNX inference fail outright. The Phase 4
# tools set YOLO_AUTOINSTALL=false to prevent that; keep the CPU build below
# unless you have verified CUDA 13 + cuDNN 9 for onnxruntime-gpu.
